KEY FEATURES

압도적인 기술력의 차이

압도적 4K UHD 해상도

Ultra HD Direct type LED 패널 사용. FHD보다 월등한 선명도, 450cd/m² 밝기.

Android OS 기본탑재

Windows 호환. 최적화된 성능과 강화된 보안기능으로 누구나 쉽게 사용.

무반사 고강도 강화유리

무반사·9등급 고강도 강화유리, ZERO-GAP bonding. 경도9H로 스크래치 ZERO.

실시간 화면 녹화 및 미러링

E-share를 통한 양방향 최대 9개 동시 미러링. 카메라/고성능 마이크 탑재.

종이 같은 필기감

딜레이 없는 0.01초 반응 속도. 실제 펜처럼 씁니다. Zero Bonding 기술로 화면과 펜 사이 간격 제로.

대화형 AI 기능 탑재

통합 AI Assistant (Google Assistant, DeepSeek) 탑재. 교안생성, 편집 및 실시간 Q&A와 맞춤학습 가능.

폰 공유 솔루션

실시간 사진/동영상 공유. 학습 및 회의에 필요한 자료를 전자칠판에 실시간으로 띄워 활용 (Quick SHARE).

SOFTWARE

Powerful Software Ecosystem

Eshare 미러링

케이블 NO. 노트북/폰/태블릿 모든 OS 지원. 최대 9개 화면 공유. Touch Back 기능으로 양방향 제어 가능.

공유 & 저장

판서내용 QR코드 스캔으로 즉시 저장. 클라우드/이메일 전송. 간편한 QR코드 생성 및 파일공유.
